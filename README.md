# Посмотри в окно

Учебный проект Яндекс Практикума: приложение для просмотра коротких видео с видами из окон разных городов. Интерфейс свёрстан по макету Figma.

## Возможности

- Поиск видео по названию города и времени суток.
- Выбор текущего видео из списка карточек.
- Загрузка дополнительных карточек кнопкой «Показать ещё».
- Прелоадеры во время загрузки и сообщение об отсутствии подходящих видео.
- Навигация с клавиатуры и состояния интерактивных элементов.

## Технологии

HTML, CSS и JavaScript. Вёрстка использует Flexbox, локальные шрифты, псевдоэлементы для чекбоксов и `object-fit` для видео и изображений.

## Просмотр проекта

Точка входа — `index.html`. Для просмотра можно использовать локальный статический HTTP-сервер. Загрузка видео требует подключения к интернету.
